# DevOps Version-Controlled Project

## Task 4: Build a Version-Controlled DevOps Project with Git

This project demonstrates Git and GitHub version-control practices.

## Objectives

- Initialize a Git repository
- Create main, dev and feature branches
- Use Pull Requests
- Add README.md
- Use .gitignore
- Create Git tags
- Document the Git workflow

## Branch Workflow

feature -> dev -> main

### Main Branch
Contains the stable project.

### Dev Branch
Used for development and testing.

### Feature Branch
Used for developing individual features.

## Git Commands Used

- git init
- git add
- git commit
- git branch
- git switch
- git push
- git pull
- git merge
- git tag
- git stash
